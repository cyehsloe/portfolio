# Дарья Иванова — инженерное портфолио

Статический сайт на HTML, CSS и JavaScript. Не требует сборки и зависимостей.

## Локальный просмотр
Откройте `index.html` в браузере или запустите локальный сервер из папки проекта.

## Публикация на GitHub Pages
1. Создайте репозиторий GitHub и загрузите содержимое этой папки в корень репозитория.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.

## Перед публикацией проверьте
- Замените ссылку `https://github.com/` на свой профиль GitHub.
- Добавьте контактную почту, если хотите её публиковать.
- Проверьте точные названия и формулировки достижений.
- Если добавляете мотивационное письмо, положите PDF в `assets/documents/motivation-letter.pdf`.
- Не загружайте личные документы с домашним адресом, телефоном и другими лишними персональными данными.

## Структура
- `index.html` — содержимое сайта.
- `style.css` — оформление и адаптивная вёрстка.
- `script.js` — мобильная навигация и интерактивность.
- `favicon.svg` — значок сайта.
- `assets/documents/` — документы для скачивания.
