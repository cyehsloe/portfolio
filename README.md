# Портфолио Дарьи Ивановой

Статический сайт-портфолио. Внешняя ссылка в проектах ведёт только на сайт проекта «ДСТ-КарьерА».

## Фотографии

Добавь изображения в папку `images`:
- `me.jpg` — портрет для главного экрана;
- `project1.jpg` — распознавание птиц для БПЛА;
- `project2.jpg` — проект «ДСТ-КарьерА»;
- `project3.jpg` — робот для экстремальных условий;
- `project4.jpg` — проект по определению влажности почвы.

## Публикация

Загрузи содержимое папки в корень репозитория GitHub Pages. В Settings → Pages выбери Deploy from a branch, ветку `main` и папку `/(root)`.
